# Security Policy

PeregrineStoop is a toolkit for **authorized** security testing only.

## Reporting a vulnerability

If you find a security issue in PeregrineStoop itself, please report it
privately to the maintainer rather than opening a public issue:

- Contact: HaiND (Post and Telecommunication Institute of Technology) -
  haind@ptit.edu.vn

Please include a description, affected version/commit, and steps to reproduce.
We aim to acknowledge reports within a reasonable time frame.

## Responsible use

This tool must only be pointed at hosts you are explicitly authorized to test
(e.g. a bug-bounty scope or a signed engagement). Every request passes a scope
gate and is recorded in an append-only audit log. Do not use PeregrineStoop
against systems you do not have permission to test.
